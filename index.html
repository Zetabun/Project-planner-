A board for thinking on

Pin up notes, photos and lists, then run string between the ones that belong together.

Pick a style

Change it whenever you like — every board can look different.

A few things to know

  • Put things upPick from the tool rail. Double-tap to write, drag to move, pull the corner to resize.
  • Join them upTap the string tool, then tap two items. Tap the string itself to label or cut it.
  • Keep trackGive things a due date, stamp them Urgent or Done, tick off checklists.
  • Write on the boardThe pen tool lets you scribble straight onto the whiteboard in marker — arrows, circles, a quick note in your own hand.
